# Происхождение демонстраций

- Autodiary: иллюстрация одного сценария аналитического ядра на синтетических данных, созданная для портфолио. Значения и события не относятся к реальной медицинской или семейной истории.
- AI Software Factory: описание рабочего цикла действующей системы — координация, исполнение, review, доработка и продолжение после остановок.
- School Lab: один выбранный учебный пример развивающейся системы по биологии и олимпиадной математике — авторская «Лаборатория дробей», включённая в библиотеку в готовом виде. Внешние изображения, шрифты и сетевые библиотеки не используются. Добавлена навигация к портфолио.
- Схемы проектов созданы для портфолио. Исторические скриншоты и презентация Autodiary сохранены из ранее публичной витрины.
