# Происхождение демонстраций

- Autodiary: иллюстрация публичного сценария на синтетических данных, созданная для портфолио. Значения и события не относятся к реальной медицинской или семейной истории.
- AI Software Factory: условный пример целевого процесса проектируемой системы; не журнал фактического выполнения задачи.
- School Lab: авторская «Лаборатория дробей», включённая в локальную учебную библиотеку в готовом виде. Внешние изображения, шрифты и сетевые библиотеки не используются. Добавлена навигация к портфолио.
- Схемы проектов созданы для портфолио. Исторические скриншоты и презентация Autodiary сохранены из ранее публичной витрины.
